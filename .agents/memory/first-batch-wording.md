On the First Batch page, the user asked: “dont state untested, but state something more positive.”

**Why:** The user wants a welcoming first-time soapmaking guide, not discouraging presentation.

**How to apply:** Frame the starter calculation as a planning guide or calculator-generated example. Preserve the purity, supplier-data, liquid-estimate, and safe-method guidance; positive wording must not imply that the example was physically tested or certified.

Detailed first-batch directions apply only to the unscented starter example with distilled water. Custom formula shopping lists should instead provide ingredient-appropriate preparation reminders.

**Why:** Different oils, fragrances, milk, and other liquids may need different temperatures and handling; a generic starter procedure must not appear tailored to arbitrary calculator inputs.

**How to apply:** Keep the method's scope explicit, and do not adapt its instructions automatically merely because a custom formula passes numerical validation.
