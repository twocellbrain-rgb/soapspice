Use Amazon Creators API rather than Product Advertising API 5.0; Amazon's current documentation says PA-API 5.0 is deprecated. Keep the Credential ID, Secret, credential Version, partner tag, and marketplace configuration server-side in Replit Secrets.

SoapSpice is supposed to be for Amazon affiliate marketing.

**Why:** The user explicitly reminded us of this product purpose and asked that Amazon's terms be respected.

**How to apply:** Keep useful original calculator/educational content and relevant shopping links. Do not confuse untracked searches with commission-generating Special Links or claim Associate membership without activation. Never invent an affiliate tag or matched product identity.

Amazon's policies reviewed on November 2, 2026 restrict Special Links and Program Content in printed/offline material. Shopping promotions must remain online and user-clicked, not automatic Amazon redirects; disclosures must be near paid links, with the required Associate statement when active.

**Why:** Future print/share enhancements could accidentally place paid links in prohibited offline output.

**How to apply:** Keep promotions out of print/PDF and formula JSON; recheck current official policies before expanding distribution. The affiliate readiness guide in the app directory links the official policies and lists owner/account steps; implementation safeguards do not guarantee Amazon approval.

Creators API catalog responses are temporary: ItemInfo and DetailPageURL content may be cached for up to one day, while Offers content has a one-hour TTL. The SoapSpice product search should remain discovery-only unless persistent API data is paired with TTL-aware refresh. Manual product entries remain the durable source for public recommendations.

Calculator product cards are matched by stable catalog ingredient ID, not display names or aliases. Do not infer a match from free-text fragrance names without a curated identity.

The owner supplied an Amazon-issued homepage affiliate link and asked to apply it across calculator shopping outputs. Use the owner-supplied Associates tag on relevant Amazon.com searches for selected oils, fragrances, sodium hydroxide, liquids, tools, and safety equipment. Keep “Check Amazon for price” labels and the required Associate disclosure. The user wants “Affiliate link” rather than “#ad” or “paid link,” with button colors matching the site and a professional, non-obstructive presentation.

**Why:** The user explicitly requested this wording and rejected the gold buttons because they did not match the site. Keep labels conspicuous and readable while avoiding large badges or overlays. Pair “Affiliate link” with a nearby plain-language commission explanation rather than relying on that label alone.

These searches are affiliate discovery links, not verified product matches or live prices; later curated product URLs must map to the matching ingredient ID.

**Why:** Persisting API-sourced titles or URLs indefinitely can violate Amazon's catalog-content cache limits; manual recommendations do not require Amazon API credentials.

**How to apply:** Keep the API search staff-only, do not expose credentials to the browser, disable HTTP/browser caching for catalog search, and never copy search results into persistent product lists without an approved refresh strategy. A homepage short link must not become every ingredient's destination: retain relevant item searches and use only the owner's actual tracking tag, never an invented one. Key curated formula recommendations by the calculator's ingredient ID so aliases and display-name changes cannot attach a card to the wrong oil.
