name: NaOH naming in SoapSpice
description: Product language convention for sodium hydroxide and the common term lye.
---

Use “sodium hydroxide (NaOH)” at first mention, then “NaOH” for calculator amounts, solution labels, and handling instructions. Define “lye” as the common soapmaking name for NaOH, not as a second calculator ingredient. Distinguish potassium hydroxide (KOH), which is not interchangeable with NaOH.

**Why:** The user asked to standardize the site because it used “NaOH” and “lye” interchangeably.

**How to apply:** Keep calculator quantities precise as NaOH; retain “lye” in glossary/search terms only when clearly defined as a common name or synonym.
