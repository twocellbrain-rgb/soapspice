---
name: Soapmaking library sourcing
description: How to represent external soapmaking articles and recipes in SoapSpice without implying ownership.
---

For external soapmaking material, publish a brief SoapSpice-written summary and a citation link to the original publisher. Do not republish the publisher's full text or photos unless reuse rights are explicit. Label SoapSpice-owned images as illustrative when they accompany an external citation.

**Why:** The library is intended to aggregate source material, but the owner provided URLs rather than permission to republish article text or images.

**How to apply:** Use this rule for new external recipes, tutorials, and references in the static SoapSpice library. Keep SoapSpice-authored or licensed full content distinct from external citations.
